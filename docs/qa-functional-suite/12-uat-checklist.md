# UAT Checklist

## Admin UAT
- [ ] Login as admin
- [ ] Create test and questions
- [ ] Publish test
- [ ] View candidate attempt analytics
- [ ] Approve/reject team registration
- [ ] Edit and revoke team
- [ ] Manage lookups/projects

## Student UAT
- [ ] Signup as student
- [ ] Login as student
- [ ] View available tests
- [ ] Start attempt and submit
- [ ] View attempt history and scores

## Team UAT
- [ ] Register team
- [ ] Login after approval
- [ ] Submit profile update request
- [ ] Submit custom idea
- [ ] Submit GitHub URL
- [ ] Update project progress
- [ ] Change password
- [ ] Password reset via OTP

## Cross-Cutting
- [ ] Unauthorized route access blocked
- [ ] Unauthorized API access returns 401/403
- [ ] Error messages are user-friendly
- [ ] Responsive layout works on desktop/mobile
